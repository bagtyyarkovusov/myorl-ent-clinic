# MyORL ENT Clinic Platform

A bilingual Greek and Russian clinic website built with Next.js, Strapi, and Meilisearch.

This repository contains the application and migration tooling used to move a legacy MODX site to a CMS the clinic team can edit themselves. It is a clean public source release. It contains no production database export, patient submissions, credentials, session data, or client documents.

## Stack

- Next.js and React
- Strapi 5
- PostgreSQL
- Meilisearch
- TypeScript
- Playwright and Vitest
- Docker

## Local development

Copy each `.env.example` to a local `.env` file, install dependencies with pnpm, and follow the app-specific README files under `apps/`.

Live site: https://myorl.up.railway.app
